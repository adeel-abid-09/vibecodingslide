📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Client (Frontend)
The part of a website the user directly sees, touches, and interacts with in their web browser (HTML, CSS, JavaScript, React). Analogy: The dining room of a restaurant.
Server (Backend)
A computer running software (like Node.js & Express) that listens for requests over the internet, enforces security rules, and processes data. Analogy: The kitchen and waitstaff.
Database
A dedicated storage vault (like MongoDB) designed to store, organize, and retrieve persistent records safely. Analogy: The restaurant pantry and walk-in freezer.
HTTP Request
A formal digital message sent from the Client to the Server asking to fetch or change data (e.g. "Please send me the menu").
HTTP Response
The reply sent back from the Server to the Client containing a status code (like 200 OK) and usually data in JSON format.
Terminal / CLI
Command Line Interface: A direct text-based conversation with your computer operating system where you type commands instead of clicking icons.
Node.js
A runtime engine that allows JavaScript to run directly on your computer or server, outside of a web browser.
npm (Node Package Manager)
The world's largest registry of free, pre-written code packages and tools that you can install in one command (like express or mongoose).
Git & GitHub
Git is a time-machine tool that tracks code history and changes. GitHub is a cloud platform where you store and share your Git repositories.

✅ The Non-Negotiable Key Takeaways

Every student must verify they understand these before leaving today's class:

  • ✔
    Client vs Server vs Database: The client is what the user touches (browser); the server is the brain/gatekeeper; the database is the permanent storage closet.
  • ✔
    The Security Golden Rule: Never connect frontend code directly to the database. All sensitive queries go through the server.
  • ✔
    The Terminal is Just a Chat Window: It's simply a text conversation directly with your computer's operating system.
