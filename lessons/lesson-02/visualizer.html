📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

The Box Model
The fundamental CSS rule that every element is a rectangular box made of 4 layers: Content (text/image), Padding (cushion inside), Border (frame), and Margin (spacing outside).
Flexbox
A CSS layout tool designed to easily distribute space and align boxes horizontally in a row or vertically in a column with simple commands.
Responsive Design
Building webpages that automatically adapt, shrink, expand, and reorganize cleanly across desktop monitors, tablets, and mobile phones.
CSS Selectors
Patterns used to target specific HTML elements for styling (e.g. tag selectors, .class selectors, and #id selectors).

✅ The Non-Negotiable Key Takeaways

  • ✔
    Everything is a Box: Web layout is simply nesting smaller boxes inside bigger parent boxes.
  • ✔
    Margin vs Padding: Margin pushes outside elements away; Padding adds cushion inside the box.
  • ✔
    Flexbox Alignment: `display: flex` with `justify-content` and `align-items` is how 95% of modern web layouts are aligned horizontally and vertically.
