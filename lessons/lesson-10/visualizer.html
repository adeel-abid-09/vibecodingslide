📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

State
The internal memory of a React component that holds values that can change over time based on user interactions (e.g. typing, clicking, toggling).
React Hook
Special functions provided by React (starting with `use`, like `useState` or `useEffect`) that allow functional components to tap into state and lifecycle features.
`useState`
The core React hook that declares a state variable and gives you an updater function (e.g. `const [count, setCount] = useState(0)`).
Re-render
The process where React re-executes a component function and repaints the screen because one of its state variables changed.
Event Handler
A function triggered in response to a user action in the browser (e.g. `onClick`, `onChange`, `onSubmit`).
Controlled Component
An input form element whose display value is strictly controlled by React state (`value={text}` and `onChange={e => setText(e.target.value)}`).
`e.preventDefault()`
A method called on form submission events that cancels the browser's default behavior of reloading the entire webpage.

✅ The Non-Negotiable Key Takeaways

  • ✔
    State Powers the UI: You never alter DOM text by hand in React. You update state (`setCount`), and React repaints the screen.
  • ✔
    Controlled Inputs: The value of every form field is bound to state (`value={name}`), and synced on every keypress with `onChange`.
  • ✔
    Prevent Page Reloads: Always call `e.preventDefault()` inside your `onSubmit` handler to prevent the browser from reloading the page.
