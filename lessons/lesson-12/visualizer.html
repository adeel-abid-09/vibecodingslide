📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Client-Side Routing
Navigating between different page views within a Single Page Application using JavaScript, changing the URL without asking the server for a new HTML file.
React Router DOM
The standard routing library for React applications that enables client-side URL routing and multi-page layouts.
`BrowserRouter`
The top-level parent component that connects React Router to the browser's native address bar and history API.
`Routes` & `Route`
Components used to map URL paths to visual page components (e.g. `} />`).
``
The React Router component used instead of `` to navigate smoothly between pages without reloading the browser window.
Dynamic Route (`:id`)
A URL segment prefixed with a colon that acts as a wildcard parameter matching any dynamic value (e.g. `/product/842`).
`useParams`
A React Router hook that extracts the dynamic parameters from the current URL path into a clean JavaScript object.

✅ The Non-Negotiable Key Takeaways

  • ✔
    `` Replaces ``: Always use `` in React to preserve state and prevent destructive page reloads.
  • ✔
    Dynamic URL Segments: Using `:id` creates a wildcard that matches any dynamic value (`/products/123`, `/products/abc`).
  • ✔
    `useParams` Hook: Extract URL params in one clean line: `const { id } = useParams()`.
