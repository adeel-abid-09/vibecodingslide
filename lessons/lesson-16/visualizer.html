📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Debounce
A programming technique that delays executing a search function until the user stops typing for a few hundred milliseconds, preventing thousands of wasted API calls.
Regex (Regular Expression)
A powerful pattern-matching syntax used in databases and code to search for text strings (e.g. matching partial words or email formats).
Case-Insensitive Search (`$options: "i"`)
A MongoDB query parameter that ignores capitalization, allowing "react" to match "React", "REACT", and "reACt".
Modular Assembly Loop
The discipline of building and verifying one feature completely (Model ➔ Route ➔ Thunder Client ➔ React UI) before starting the next feature.
Query Filtering
Combining multiple criteria in a database query (e.g. finding jobs where title matches a search keyword AND category equals "Engineering").

✅ The Non-Negotiable Key Takeaways

  • ✔
    Never Build Everything at Once: Use the 5-step assembly loop to build, test, and commit one feature at a time.
  • ✔
    Case-Insensitive Search: In MongoDB, `{ title: { $regex: query, $options: 'i' } }` handles case-agnostic text searching effortlessly.
  • ✔
    API First Testing: Always test new endpoints with Thunder Client before wiring them to React to isolate bugs immediately.
