📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

CRUD
The 4 fundamental operations of any database system: Create (POST), Read (GET), Update (PUT), and Delete (DELETE).
MVC (Model-View-Controller)
A professional software architecture pattern that separates an app into 3 distinct layers: Model (data rules), View (the UI), and Controller (business logic).
Controller
A dedicated JavaScript file containing the actual worker functions that extract user input, query MongoDB with Mongoose, and return JSON responses.
Router
An Express module (`express.Router()`) that maps clean URL paths to their respective controller functions.
`try / catch`
A JavaScript safety net: code in `try` executes normally, and if any unexpected database error occurs, `catch` intercepts it so your server doesn't crash.
`findByIdAndUpdate`
A Mongoose query method that searches for a document by its unique `_id` and applies modifications, returning the updated document when `{ new: true }` is passed.

✅ The Non-Negotiable Key Takeaways

  • ✔
    MVC Separation: Routes handle the HTTP paths; Controllers handle the database work; Models guard the data shape.
  • ✔
    The Essential 4: `find()`, `create()`, `findByIdAndUpdate()`, and `findByIdAndDelete()` power 90% of web apps.
  • ✔
    Always use `try/catch`: If your database goes down or queries fail, `try/catch` catches the error and sends a clean 500 status rather than crashing your entire server.
