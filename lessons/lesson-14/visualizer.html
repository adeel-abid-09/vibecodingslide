📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Origin
The combination of Protocol (`http`), Domain/Host (`localhost`), and Port (`5173`). Two URLs are only same-origin if all three match exactly.
CORS (Cross-Origin Resource Sharing)
A browser security mechanism that restricts web pages from making API requests to a domain or port different from the one that served the page.
Same-Origin Policy (SOP)
A critical browser security rule that stops malicious scripts on one website from secretly making requests to another website where you are logged in.
Preflight Request (OPTIONS)
An automatic preliminary check sent by the browser to the backend asking: "Does your server permit requests from my origin, with my headers?"
`Access-Control-Allow-Origin`
The HTTP header sent by the Express server telling the browser which client origins are permitted to access its data (e.g. `*` or `http://localhost:5173`).
Axios Interceptor
A global middleware hook in Axios that automatically injects headers (like `Authorization: Bearer `) into every outgoing request before it leaves the browser.
Monorepo
A software repository structure where both the frontend (`client/`) and backend (`server/`) codebases live together in one organized project folder.

✅ The Non-Negotiable Key Takeaways

  • ✔
    CORS is Browser-Enforced: Postman never has CORS issues; only browsers enforce CORS to protect users from malicious scripts on other domains.
  • ✔
    The 2-Line Backend Fix: `const cors = require('cors'); app.use(cors());` tells all browsers that your API is open for business.
  • ✔
    Environment Portability: Never hardcode `http://localhost:5000` inside React components. Always use `VITE_API_URL`.
