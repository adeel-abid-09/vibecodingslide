📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Stack Trace
A detailed error report printed by Node or the browser showing the exact chain of functions called and the exact file and line number where code failed.
Syntax Error
A spelling or grammatical mistake in your code (like a missing bracket or unclosed quote) that stops the program from even starting.
Runtime Error
A crash that happens while the program is actively running (such as trying to read properties from an `undefined` variable).
Console Tab
The browser DevTools panel that logs messages, warnings, and unhandled JavaScript runtime exceptions.
Network Tab
The browser DevTools panel that records every HTTP request, showing status codes (200, 404, 500), payloads, headers, and latency.
`TypeError: Cannot read properties of undefined`
The most common JavaScript crash: attempting to access a property or call a method (like `.map()`) on a variable that has not yet received its data.

✅ The Non-Negotiable Key Takeaways

  • ✔
    Errors are Roadmaps: Read the file name and line number in red text. The error tells you exactly where the problem originated.
  • ✔
    Default Your State: Always initialize array state as `useState([])` to prevent `undefined.map` crashes while waiting for data.
  • ✔
    Feed AI the Truth: Never summarize an error into "it didn't work". Always paste the raw text of the error alongside the source file.
