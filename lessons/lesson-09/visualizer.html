📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

SPA (Single Page Application)
A modern web architecture where the browser loads one single HTML page, and JavaScript dynamically updates the screen without white flashes or page reloads.
Component
An independent, reusable piece of user interface (like a button, card, or navbar) written as a JavaScript function that returns JSX.
JSX (JavaScript XML)
A syntax extension for JavaScript that looks like HTML, allowing you to design user interfaces directly inside your React components.
Props (Properties)
Read-only arguments passed from a parent component down to a child component (e.g. ``).
Component Tree
The hierarchical parent-child diagram showing how components are nested inside each other to form a complete webpage.
Virtual DOM
React's lightweight in-memory copy of the real browser DOM, used to calculate the fastest, minimal updates before repainting the screen.
Vite
A blazing-fast next-generation frontend build tool and development server used to create modern React applications.

✅ The Non-Negotiable Key Takeaways

  • ✔
    Components are Custom Lego Bricks: Break any webpage into independent, reusable functions that return visual JSX.
  • ✔
    Props Flow Downwards: Parents give data to children through props (``); children never alter parent props directly.
  • ✔
    SPA Fluidity: React updates only the specific elements that changed without ever reloading the entire browser window.
