📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Runtime Environment
The engine and ecosystem that executes code. Node.js is a server-side runtime, while V8 in Chrome is a browser-side runtime.
Port
A numbered software doorway on your computer (e.g. 5000 or 5173) where specific network programs listen for incoming internet traffic.
Express.js
A minimalist, fast web server framework for Node.js that simplifies routing, middleware, and request handling.
Request (`req`)
The object provided by Express containing everything the user sent: URL parameters, query strings, headers, and request body payload.
Response (`res`)
The object provided by Express used to craft and send the reply back to the user: setting status codes (`res.status(200)`) and JSON data (`res.json(...)`).
Middleware
A helper function that intercepts an incoming request before it reaches your final route handler, often used for parsing data, logging, or checking passwords.
`express.json()`
A mandatory built-in Express middleware that translates incoming raw JSON text streams into a ready-to-use JavaScript `req.body` object.
Nodemon
A developer utility that automatically restarts your Node server whenever you save changes in your code, saving you from manually restarting it in the terminal.

✅ The Non-Negotiable Key Takeaways

  • ✔
    What is a Port? A numbered doorway (like 5000) on your operating system where incoming requests are received.
  • ✔
    The Role of `req` and `res`: `req` contains the user's data; `res` sends the server's reply.
  • ✔
    Why `express.json()` is mandatory: Without it, Express cannot read JSON payloads sent in POST requests and `req.body` will be `undefined`.
