📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Side Effect
Any operation that reaches outside of a component's pure rendering logic (e.g. fetching data from an external API, setting timers, or altering browser storage).
Mounting
The exact moment when a React component is first rendered and inserted into the browser's visible DOM tree.
`useEffect`
The React hook used to safely run side effects after a component mounts or after specified state values change.
Dependency Array `[]`
The second argument passed to `useEffect`: an empty array `[]` tells React to run the effect only once when the component first mounts.
Axios
A popular, feature-rich promise-based HTTP client library for JavaScript used to make GET, POST, and DELETE requests to backend APIs.
Loading State
A temporary UI state displayed while waiting for asynchronous network data to arrive, preventing blank screens using spinners or skeleton loaders.
List Key (`key={item._id}`)
A unique string attribute required by React when mapping over lists so it can track, update, or remove individual elements efficiently.

✅ The Non-Negotiable Key Takeaways

  • ✔
    The Empty Dependency Array `[]`: Always pass `[]` as the second argument to `useEffect` to ensure it only runs once when the component appears.
  • ✔
    The 3 UI States: Never leave users staring at a blank screen. Always design for Loading (spinner), Error (banner), and Success (cards).
  • ✔
    Every Mapped Element Needs a `key`: React requires `key={item._id}` so it can efficiently update DOM elements when items change.
