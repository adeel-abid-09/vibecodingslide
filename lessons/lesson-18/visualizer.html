📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Localhost
A hostname that means "this local computer only". Servers running on localhost are invisible to anyone outside your private machine.
Production Build (`npm run build`)
The process of compiling, optimizing, and minifying your source code into ultra-fast, compact static files ready for deployment.
CDN (Content Delivery Network)
A worldwide network of distributed servers (like Vercel or Cloudflare) that caches and serves your frontend files from the server closest to the visitor.
Cloud Web Service (Render/Railway)
A platform that hosts your live backend Node.js server 24/7 on cloud virtual machines connected to the public internet.
SPA Rewrite Rule (`vercel.json`)
A server configuration that redirects all incoming URL requests back to `index.html` so React Router can handle page navigation without 404 errors.
CI/CD (Continuous Integration / Continuous Deployment)
An automated pipeline where pushing new code to GitHub automatically triggers a build and updates your live deployed website within minutes.

✅ The Non-Negotiable Key Takeaways

  • ✔
    `localhost` vs The Cloud: Localhost only lives on your private computer. Deployment moves your code to public cloud servers reachable anywhere on Earth.
  • ✔
    Vercel SPA Rewrites: Always configure `vercel.json` rewrites so that page refreshes on subroutes like `/dashboard` don't return 404.
