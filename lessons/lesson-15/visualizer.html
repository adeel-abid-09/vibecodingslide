📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

PRD (Product Requirements Document)
A comprehensive blueprint describing what problem a product solves, who will use it, the full list of features, and technical constraints before coding.
User Story
A feature description written from the perspective of an end-user: "As a [user type], I want to [action], so that I can [benefit]".
Data Modeling
The architectural process of defining which data entities exist, what fields they contain, and how they reference each other in a database.
API Specification (Contract)
A formal table documenting every endpoint URL, supported HTTP verb, required headers, request payloads, and expected status codes.
Scope Creep
The dangerous tendency for a software project to continuously expand with unplanned features, leading to unfinished, buggy applications.
MVP (Minimum Viable Product)
The simplest, most focused version of a product that successfully delivers its core value proposition to users.

✅ The Non-Negotiable Key Takeaways

  • ✔
    Spec Before Code: Vague prompts produce broken code. When you specify schemas and routes first, AI outputs flawless code.
  • ✔
    The 3 Layers: Every feature must be planned across Database Models ➔ Express Endpoints ➔ React Components.
  • ✔
    Scope Control: Build a polished core loop with 3 great features rather than a broken app with 20 half-finished buttons.
