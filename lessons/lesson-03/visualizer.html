⏳ The Async / Await Mental Model

Why do we use `await`? Because servers live thousands of miles away: 

sequenceDiagram
    autonumber
    participant App as Browser Code
    participant API as External Server

    App->>App: 1. Code executes instantly (Line 1, Line 2)
    App->>API: 2. const res = await fetch("/api/data")
    Note over App: ⏸️ Function PAUSES here without freezing browser
    Note over API: Server processes query & builds response (150ms)
    API-->>App: 3. Returns HTTP Response (Status 200)
    App->>App: 4. Function RESUMES and unpacks data!

📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

Primitive Data Types
The simplest building blocks of data: String (text), Number (digits), Boolean (true/false), null (intentional emptiness), and undefined (unassigned variable).
Object `{}`
A container that groups related properties and values under labeled keys (e.g. `{ name: "Laptop", price: 999 }`).
Array `[]`
An ordered list of items accessed by their numerical index starting at 0 (e.g. `["Apple", "Banana", "Cherry"]`).
JSON (JavaScript Object Notation)
The lightweight, human-readable universal text standard used across the internet to exchange data between clients, servers, and databases.
Function
A reusable machine of code that takes Inputs (arguments/parameters), runs a calculation or transformation, and gives back an Output (return value).
Asynchronous (Async)
Code that runs in the background without freezing the rest of your program while waiting for slow operations (like fetching data from a server 3,000 miles away).
`await`
A JavaScript keyword placed before a slow asynchronous task that says: "Pause this function right here until the server replies, but let the rest of the computer keep running."
Array Methods (.map, .filter)
`.map()` transforms every item in an array into something new (like converting raw objects into HTML cards). `.filter()` weeds out unwanted items based on a condition.

✅ The Non-Negotiable Key Takeaways

  • ✔
    Objects vs Arrays: An Object `{ key: "value" }` describes one thing; an Array `[ item1, item2 ]` holds a list of things.
  • ✔
    Dot Notation: `user.orders[0].price` walks directly down the JSON tree to grab the exact piece of data needed for the UI.
  • ✔
    Async/Await is Waiting: You use `await` whenever you reach outside your computer (fetching from an API or reading a database).
