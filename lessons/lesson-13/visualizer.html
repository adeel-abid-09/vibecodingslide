📖 Lesson Vocabulary & Core Terminologies

Essential technical jargon explained in plain English for beginners:

`localStorage`
A persistent key-value storage system built into the browser that retains saved data (like JWT tokens) even after closing or refreshing the tab.
Prop Drilling
The awkward, error-prone process of passing props down through many layers of intermediate child components that don't actually need the data themselves.
React Context API
A built-in React system that creates a "global broadcasting station", making data (like logged-in user auth) accessible to any component instantly.
`createContext` & `Provider`
`createContext()` initializes the shared context vault; `` wraps your app and broadcasts data to all children.
Custom Hook (`useAuth`)
A user-created helper hook that packages Context consumption into a clean, single-line call: `const { user, logout } = useAuth()`.
Protected Route
A component wrapper that checks if a user is authenticated; if yes, it renders the private screen; if no, it redirects them to `/login`.
``
A React Router component used inside route guards to immediately redirect unauthorized visitors to a different page.

✅ The Non-Negotiable Key Takeaways

  • ✔
    Context Eliminates Prop Drilling: Auth state is broadcast globally to all components without passing props down through every layer.
  • ✔
    Persistent Sessions: Saving the token in `localStorage` ensures the user remains authenticated even when refreshing the page or reopening the tab.
  • ✔
    Route Gatekeeping: Wrapping pages in `` protects user privacy by redirecting unauthorized visitors to `/login`.
